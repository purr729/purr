# NEON DRIFT

키보드와 모바일 터치로 플레이하는 **단일 HTML 네온 레이싱 게임**입니다. 외부 라이브러리나 설치 과정이 필요하지 않습니다.

## 실행
`index.html`을 브라우저에서 열면 바로 시작합니다. GitHub Pages와 정적 웹 호스팅에서도 실행 가능합니다.

## 조작
- **← / →** 또는 **A / D**: 좌우 차선 변경
- **Space / P**: 일시정지 / 계속
- **R**: 처음부터 다시 시작
- **모바일**: 좌우 버튼 또는 스와이프 / 좌우 터치

## 규칙
- 도로의 적 차량을 피해서 오래 살아남으세요.
- **노란 에너지 링**을 모으면 점수 **+50**.
- **청록 보호막**을 모으면 **6초**간 충돌 방어.
- 생명 3개를 모두 잃으면 게임 종료.
- 최고 점수는 브라우저의 로컬 저장소에 저장됩니다.

## 파일 구성
`index.html` 하나에 전체 HTML, CSS, JavaScript 게임이 포함돼 있습니다.
